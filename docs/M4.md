# M4: secondary features. Guide for contributors

M4 implements the features deferred in M1–M3 (`docs/compat.md` §4: DC-030…034, DC-045) plus `--convert-control`. No M4 feature is deprecated upstream: biber 2.22 deprecates only `bblxml` output, which is dropped (DC-020). Read `docs/PLAN.md`, `docs/M2.md` (its conventions apply unchanged) and `docs/compat.md` first.

The goal is unchanged: byte-identical output, logs (modulo §5 of compat.md) and exit codes, compared with biber 2.22 (oracle O1, the TeX Live binary, and O3, `tools/oracle/biber-src`).

Package boundaries: tool owns `output/bibtex.rs` and the tool pipeline; bltxml owns `pipeline/fetch/biblatexml.rs`, `output/biblatexml.rs` and schema generation; xml owns `crates/relaxng` and the convert-control renderer; io owns remote fetching and `perl-compat`/encoding code. Shared files (`run.rs`, `cli.rs`, `config/`, `pipeline/mod.rs`, `quirks.rs`) take small additive edits only.

## Conventions (in addition to docs/M2.md)

- **Dependencies:** prefer small, pure-Rust crates (`rustls` over OpenSSL, `encoding_rs` only where its output matches Perl `Encode` byte for byte, otherwise generated tables). Every new dependency must build on macOS, Linux and Windows (CI) with `PCRE2_SYS_STATIC`-style static linking, and needs no network at build time.
- **Clean-room rules:** as for btparse, don't translate LGPL/MIT C code (libxml2, libxslt); implement from specifications and black-box behaviour.
- **Corpus:** every implemented feature gets corpus cases (`tests/corpus/<suite>/<case>/`, goldens from O1 via `cargo xtask golden`) and joins `tests/corpus/passing.txt`. Remove the feature's `deferred:` tag and the `unsupported()` gate in `crates/bibers/src/run.rs` when it lands.
- **Report, don't edit:** `docs/biber-bugs.md`, `docs/compat.md`, `docs/PLAN.md` are edited by the coordinator. Your final report lists new biber bugs (with a minimal reproduction), intended differences (proposed DC rows), and Quirk switches added.
- **Commit** on your branch with clear messages; run `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` and `cargo xtask corpus` before reporting.
