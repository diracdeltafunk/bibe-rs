# Test-only TLS material

These keys and certificates are **for tests only**. They are self-signed, generated by `gen.sh`, and used by the local HTTPS test server in `crates/testkit/src/servers.rs`, which listens on 127.0.0.1 during `cargo test` and `cargo xtask remote`. They protect nothing and are not secrets; secret scanners that flag the `*.key` files here can ignore them.
