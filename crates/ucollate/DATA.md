# ucollate data files: provenance and licences

All files in `data/` are generated by `tools/oracle/probes/ucollate/gen-data.pl`, run
under oracle O3's perl 5.42.0 with **Unicode::Collate 1.31 / Unicode::Collate::Locale
1.31** (the versions bundled in the biber 2.22 binary):

```sh
/Users/ben/bibe-rs/vendor/perl/bin/perl tools/oracle/probes/ucollate/gen-data.pl crates/ucollate/data
```

The script refuses to run against any other module version and prints the SHA-256 of
each output. Current values:

| File | SHA-256 | Content |
|---|---|---|
| `allkeys-13.0.0.txt` | `a3255d45b7af97f4dc14fb8364d7573b434425e5c58cacf00d16901ce081c78d` | Verbatim copy of `Unicode/Collate/allkeys.txt`: the DUCET 13.0.0 (`@version 13.0.0`, 2020-01-28). `build.rs` compiles it into static tables. |
| `locales.txt` | `7f5f21d145bda51573039d4b1eced90479ff6744e5f5bee9e8f2c9a26e3fa5c4` | The 87 `Unicode/Collate/Locale/*.pl` tailorings, in order of file name. Each starts with `@locale <file stem>`, followed by its scalar options (`@locale_version`, `@upper_before_lower`, `@backwards`, `@variable`/`@alternate`, `@suppress`, `@overrideCJK <table>`) and its `entry` lines in allkeys syntax with comments and names removed. Parsed lazily at run time, one locale at a time. |
| `cjk.txt` | `a11989f11f0ed96c09a24ce95601f50af49f0c68e522b77993a53d340ac0db56` | What the seven `overrideCJK` callbacks (`Unicode::Collate::CJK::{Big5,GB2312,JISX0208,Korean,Pinyin,Stroke,Zhuyin}`) return. Each callback was called for every code point in U+3400..U+9FFF, U+F900..U+FAFF, U+20000..U+2FFFF and U+30000..U+3134F, and the defined results were recorded. Single primary weights are stored as runs (`W CP CP …`: the code points get W, W+1, …). Multi-element results (Korean) are stored as `CP=ITEM …`. Parsed lazily when a ja/ko/zh* collator is first created. |

The extraction only *runs* the Perl modules and records their data. No module code is
translated. The algorithm in `src/` was written from UTS #10 and the Unicode::Collate
POD, and then verified by differential testing (`tests/differential.rs`).

## Test data (`tests/data/`)

* `digests-{allcp,locales,options}.txt`: one line per differential suite, giving the
  suite name, the number of input strings and the md5 of the oracle's sort keys. The keys
  are written in hex, one per line. Suites are defined in `tests/common/suites.rs`.
  These files are produced by
  `UCOLLATE_BLESS=1 cargo test -p ucollate --release --test differential -- --ignored`.
* `locale-names.tsv`: 8059 locale names and the locale `Unicode::Collate::Locale`
  accepts for each (`getlocale`). Produced by the same command.
