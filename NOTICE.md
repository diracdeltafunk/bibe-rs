## Unicode data

These files are under the Unicode License v3 ([LICENSES/Unicode-3.0.txt](LICENSES/Unicode-3.0.txt)), © Unicode, Inc.:
- `crates/ucollate/data/allkeys-13.0.0.txt`: the Default Unicode Collation Element Table (DUCET) 13.0.0, © 2020 Unicode, Inc.

## BibTeX parsing

The `btparse` crate is a new implementation written from a behavioural specification ([docs/spec/btparse.md](docs/spec/btparse.md)) and black-box tests. It contains no code from btparse (Text::BibTeX), which is LGPL-2.0-or-later.
